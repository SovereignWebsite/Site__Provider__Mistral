Two ways to reach Mistral

Way 1, in use

The API: our code calls a Mistral model

A program (a page in your browser, or a script an agent runs) sends a request to Mistral’s API and gets an answer back. The program decides everything; the model only answers. This is how every demo and recorded run on this site works.

  • Mistral’s API reference lists the families a program can call: chat, responses, fill-in-the-middle, embeddings, classifiers, files, models, batch, OCR, audio (transcription, speech, voices), realtime sessions and workflows. (Mistral API reference, read 22 November 2026)
  • Two hosts: the global endpoint, api.mistral.ai, and the EU endpoint, api.eu.mistral.ai, the one that commits to processing in the EU. (this site’s sources, read 20 November 2026)
  • In public preview: agents, conversations, libraries, connectors, prompts, skills, observability, service accounts and an admin family; fine-tuning and the old agents endpoints are marked deprecated. (Mistral API reference, read 22 November 2026)

On this site: the studio (every demo, with your own key), Mistral in this tab (no key), evals, the Swarm, workflows, PrompTugal.

Way 2, to build

The loop: Mistral as the agent

The model runs the loop itself: it reads a repository, chooses its next step, runs tools, and commits its work, as the Claude agents that built this site do. For that a Mistral agent needs a loop to run in, a way to reach GitHub, and a signing key of its own.

  • Mistral Vibe is Mistral’s own coding agent for the terminal, open source under Apache 2.0, installed with uv tool install mistral-vibe or Mistral’s install script. (github.com/mistralai/mistral-vibe, read 22 November 2026)
  • It runs without a person: vibe --prompt "…" does one task and exits, with a cap on turns, JSON output and auto-approval of tools; it reads the key from MISTRAL_API_KEY. That is the loop a Mistral agent here would run in. (Vibe: work with the CLI, read 22 November 2026)
  • Managed Agents (public preview) run on Mistral’s side; an agent has no shell or files unless it is given them. (Mistral Managed Agents, read 22 November 2026)
  • An agent can be given a GitHub connector, once it is connected in the console, and remote MCP servers, with their credentials passed by the name of an environment variable. (Agents: connectors, read 22 November 2026)
  • Le Chat is now called Vibe; in its web app a “GitHub App” connector searches repositories, reviews issues and manages pull requests, and an administrator can add remote MCP connectors. (Vibe: connectors, read 22 November 2026)

The plan. One Mistral agent, Mistral Vibe running headless in its own container, working on this repository on a branch only: it reads its brief from the repository, does one small job (a summary of the day’s commits), and opens the change for review. The same rules as the Claude agents: its own published signing key, the dev branch only, every call logged with its cost, nothing pushed to main. Nothing of this runs yet; it starts only at Dinis Cruz’s word.

The agents

Every agent that has worked on this site, by name. Each signs its own commits with its own key.

  • conductor.mistral /: Splits the work, sets the rules, reviews and assembles the site, and commits it.
  • swarm.mistral /swarm/: The Swarm run on Mistral, replayed call by call.
  • evals.mistral /evals/: Evals for a site's jobs, run on Mistral models, with every check published.
  • team.mistral /team/: Seven agents inside the site, live on Mistral, with recorded runs.
  • mistral.local /browser/local/: Ministral 3 3B running inside the browser tab.
  • mistral.promptugal /promptugal/: The /promptugal/ section.
  • mistral.workflows /workflows/: Complex agent workflows on Mistral, side by side, in the style of the Web Summit stand.
  • mistral.design /: The site's navigation, in hourly design rounds.
  • mistral.c: this page, the inventory below, and the first workflows run on Mistral for the team. Started on 22 November 2026.

The agents above ran on Claude, on Dinis Cruz’s account B, from 20 to 21 November 2026; that account is paused at its limit. Their states are on Agents at work, from the roster. Reviewers (security, design, the factory, the budget) are listed there too.

The console

Mistral has two consoles: Studio, at console.mistral.ai, for building (agents and their connectors among them), and the admin panel, at admin.mistral.ai, for the organisation: workspaces, members, roles and groups, single sign-on, subscriptions and billing, audit logs and usage limits. (Mistral admin overview, read 22 November 2026)

There is a public admin API (organisation, members, workspaces, access) for Enterprise plans only, and the API reference lists admin endpoints in preview for users, workspaces, API keys, billing and audit logs. (Mistral admin API, read 22 November 2026)

The plan. A better console of our own, as a page on this site: it runs in your browser, holds your key in the tab only (as the key vault and the demos do), and shows in one place what Mistral’s API can tell it: the models your key can use and their prices, your files, batch jobs and fine-tuning jobs, your agents and libraries, and this site’s own ledgers. What the API cannot show (billing, members, usage by key) stays a link to Mistral’s console. Nothing is built yet; it goes through the security review before it takes a key.

Mistral’s models are also sold through AWS (Amazon Bedrock), Azure and Google Cloud Vertex AI; this site uses Mistral’s own API, not a cloud reseller, so the data goes to Mistral only. (Mistral cloud deployments, read 22 November 2026)

What it has cost

Every Mistral call our agents made was logged with its tokens and priced at Mistral’s list prices (as read on 20 and 21 November 2026). In all: about 1.17 USD for 1,326 logged calls, plus PrompTugal’s, whose count is in its hand-over.

Mistral API spend by agent, from each agent’s own record

What this says. The Mistral calls were the small part of the bill. Two of the agents’ own hand-over notes record that each Claude session was stopped at a 20 USD session-cost rule, while their Mistral calls came to cents. Moving the routine work (summaries, triage, drafts, drains) onto Mistral models is cheap; the cost to watch is the agent that runs the loop.

The image calls by the design agent are booked by their own record in studio-images.json and not counted here. Pictures have no published price.
