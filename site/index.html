Build with a European brain

A first call to a Mistral model in five minutes, on your own laptop with no key, or with your own key. Then build something a sovereign website could use.

For participants of the Mistral Vibe Hackathon, organised by Mistral: 8:30 to 20:30, teams of 3 to 5, 18 and over. Venue, schedule and rules are on the organisers' event page (as read on 21 November 2026). This site is independent and not part of the event.

Sovereign means you can choose, and change, who runs your model. The ledger asks five questions of any AI you depend on.

Start here

  1. Pick a path. A model on your laptop with Ollama (no key), or your own Mistral key.
  2. Make one call. Copy the five-minute recipe below.
  3. Open the demos. Run the same brief on Mistral beside another model.
  4. Build. Ideas below; anything that makes the model a choice counts.
  5. Share it. A public repository you own, and the link.

Five minutes to a first call

No key needed: a model on your laptop

  1. Install Ollama.
  2. Pull the smallest Ministral 3 and call it:
ollama pull ministral-3:3b

curl http://localhost:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "ministral-3:3b",
       "messages": [{"role": "user", "content": "Say hello in five words."}]}'

Ollama lists ministral-3 with the tags 3b, 8b and 14b.⁠1 Ollama serves an OpenAI-style endpoint at http://localhost:11434/v1/chat/completions.⁠2 Ministral 3 was announced on 2 December 2025 in 3B, 8B and 14B sizes, for edge and local use, each with image understanding, under Apache 2.0.⁠3

With your own Mistral key

  1. Get an API key from the Mistral console.
  2. Put it in your terminal in place of your-key-here, and run the call. Never paste a key into a shared document or a commit.
export MISTRAL_API_KEY=your-key-here

curl https://api.mistral.ai/v1/chat/completions \
  -H "Authorization: Bearer $MISTRAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "ministral-3b-2512",
       "messages": [{"role": "user", "content": "Say hello in five words."}]}'

Free mode is the default for new accounts, with the lowest rate limits. Mistral’s key quickstart asks for “a plan with API access”; whether Free mode needs a payment card today was not confirmed.⁠4 In Free mode, Mistral may train on your API calls unless you switch it off in the Admin panel, under Privacy: send nothing confidential.⁠5 Ministral 3 3B, model name ministral-3b-2512, is listed as Apache 2.0, released 2 December 2025, at 0.10 dollars per million tokens in and 0.10 out.⁠6 For processing in the EU, change the address to api.eu.mistral.ai, at 1.1 times the price, once you have checked it serves the model.⁠7

Same request, different address: that is the whole idea.

What to build

  • A model picker. One OpenAI-style interface, with the owner’s choice of model behind it.
  • An open eval. The same brief on Mistral beside other models, with the tokens and time shown. See the evals.
  • A measurement. Ministral 3 on a Raspberry Pi or a tablet, timed and published. Today the fit is an estimate, not measured.⁠8 Mistral’s official compressed (Q4_K_M) files are 2.15 GB for the 3B and 5.20 GB for the 8B, plus about 0.85 GB for vision. Those are download sizes, not memory use or speed.⁠9
  • A sovereignty check. Who holds the keys, where it runs, which licence, how long data is kept, can you leave. See the ledger.

Before you serve a model to others, check its licence. Ministral 3, Mistral Small 4 and Voxtral Small are labelled Apache 2.0. Mistral Large 4 is under a modified MIT licence: its announcement says a company offering it as a model-as-a-service needs a separate commercial licence, while Mistral’s help centre describes the condition as a monthly revenue threshold of 20 million dollars. The pages disagree; read the licence file itself before relying on either.⁠10

How to share what you build

  • Put it in a public repository you own, so it can move anywhere.
  • Say in the README which path you used (a local model, your key, or another provider) and which model.
  • Check there is no key in it before you push.
  • Post the link where the organisers ask.
