In your browser, on your machine

Mistral, inside your browser

Ministral 3 3B, Mistral's own Apache 2.0 model, running inside this tab. No key, no API, no server: the weights download once from Mistral's repository on Hugging Face, and every word after that is worked out by your own machine. This is the first level of A European brain for a sovereign website, "on the device", in the one place every visitor already has.

Before you download: what to expect

  • The download is 2.15 GB, once: Mistral's own file Ministral-3-3B-Instruct-2512-Q4_K_M.gguf, from huggingface.co/mistralai/Ministral-3-3B-Instruct-2512-GGUF (size from Hugging Face's file listing, 1 GB = 109 bytes, as read on 21 November 2026). It is kept in this browser's private storage for this site, so a reload does not download it again. You can delete it below.
  • It needs about 3 GB of free memory while it runs: the 2.15 GB of weights plus room for the conversation. Phones will very likely not cope; the system may close the tab. Use a laptop or desktop.
  • Speed depends on your machine. With WebGPU (recent Chrome or Edge, with a graphics adapter) the engine runs the model on the graphics chip. Without it, it runs on the processor through WebAssembly, on one thread, which is slow. The recorded run below shows the slow case: about 1 token per second, measured in a cloud container on one WebAssembly thread with no WebGPU. A laptop with WebGPU should be much faster, but we have not measured one.
  • Tested in Chromium only (version 157). Firefox and Safari lack features this engine build needs and may fail to load the model; we say so rather than guess.

2. Download and load the model

Pressing the download button downloads 2.15 GB from Hugging Face (huggingface.co and its download servers), which see your IP address, as any download does. It is stored only in this browser until you delete it. On mobile data this may cost you. Nothing is fetched before you press it.

The conversation uses the same OpenAI-style list of messages (system, user, assistant) as the other demos on this site. It is kept in this tab's memory only, and gone when you reload.

4. What leaves this machine

  • The download of the weights, when you press the button: your browser asks huggingface.co for Mistral's file and for its small checksum record, and Hugging Face redirects the file itself to one of its file servers under hf.co (in our test, us.aws.cdn.hf.co; the name may differ where you are). Like any download, those servers see your IP address and which file you fetched. Nothing you type is sent with these requests. Loading it again later, from this browser's storage, contacts nobody.
  • Nothing else. Your messages, the model's answers and the speed figures stay in this tab. There is no key and no API call. The page's content security policy lets it connect only to this site and to those Hugging Face hosts, so it could not send your words elsewhere even by mistake.

    How it works, and what it does not claim

    • The engine is wllama 3.13.0 (MIT), which is llama.cpp (MIT, release b12211) compiled to WebAssembly, with WebGPU support. Its files are served from this site, in vendor/wllama/, with its licence; nothing comes from a script CDN. We changed one thing: the library builds its two background workers from in-memory text, and we save that same text as two files on this site so the page can forbid any other script. make-vendor.mjs does it and says how.
    • Ministral 3 3B Instruct is Mistral's model, released under Apache 2.0 for edge and local use (mistral.ai/news/mistral-3; licence from the model's Hugging Face page, both as read on 21 November 2026). Q4_K_M is Mistral's own 4-bit compressed version. The page uses the text part only; the vision part (0.84 GB more) is not downloaded.
    • The file is pinned to one version of Mistral's repository (commit eb599d40), so what you download is what we tested.
    • A 3B model is small. It writes fluent short text, and it can be confidently wrong about facts. Check anything that matters.
    • Speeds on this page are measured, not estimated: in your browser for your runs, and in a cloud container for the recorded run, which says so.
