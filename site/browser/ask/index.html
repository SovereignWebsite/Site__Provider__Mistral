In your browser, on Mistral

Ask this site

A chat that answers only from this site's own pages. A Mistral model you choose, called from this page with your own key, has three tools: list this site's pages, search them, and read one. The tools run here, in your browser, and read the pages from this site. The answer streams in, links the pages it used, and says plainly when the site does not say.

1. Replay recorded examples (no key needed)

Three questions we asked through Mistral's API, saved as a file on this site: two the site answers, one it does not. Replaying them sends nothing anywhere.

4. What this call sends, and to whom

Built before anything is sent, and updated before each call. The pages the tools read are fetched from this site by your browser; only their text goes on to Mistral, inside the next call.

How it works, and what it does not claim

  • The tools are this site's own /team/sitetools.js, written for the team inside the site: list_pages follows the site's links from the home page (up to 40 pages), read_page returns a page's visible text, and search_site finds lines that contain your words. They read only from this site's own address.
  • Every tool result goes back to the model inside <untrusted-data> markers, with the instruction that it is material, never instruction, so a page cannot tell the model what to do. Answers are shown as text; a link in an answer becomes clickable only if it points at a page of this site.
  • The model is told to answer only from the pages and to say "This site does not say." otherwise. It can still be wrong: follow the links and check.
  • The streamed chat and the tool loop are ported from PrompTugal News's chat-core.js (Apache-2.0), pointed at Mistral: chat-core.js.
  • This page talks to two places only: this site (to read its pages and the recorded examples) and the Mistral endpoint you choose, with your key, when you press Ask or ask for the model list. Its content security policy enforces that.
