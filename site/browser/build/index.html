In your browser, on Mistral

Vibe-build a sovereign website

Write a brief. An agent on a Mistral model you choose, called from this page with your own key, writes a small static website into a folder that lives only in this tab, using four tools: write a file, read a file, list the files, and check the site against this site's own rules. It keeps going until the rules pass or it reaches the step limit. You watch every tool call, see the result in a preview that cannot run script, and leave with a zip of your own files.

1. Watch a recorded run first (no key needed)

A run we made through Mistral's API, saved as a file on this site. Replaying it sends nothing anywhere: the page reads the file and plays the same tool calls into a fresh folder.

Read what it wrote. In this run the brief gave no facts about the shop, yet the model still wrote "We offer a wide selection of cheeses from around the world". The rules cannot catch a claim like that; only you can. That is why the zip's note asks you to check every sentence.

      How it works, and what it does not claim

      • The rules check_site applies are this site's own house rules, written again in JavaScript in engine.js: an index page, a title and a language on every page, no em dashes, no inline script or style (and here no JavaScript at all), nothing loaded from another site, no key-shaped strings, and no broken links inside the site. Passing them does not make a site good, true or accessible; it makes it clean. Read what the model wrote.
      • The model is told never to invent facts, and to leave a [placeholder] where the owner must add one. Small and large models still make mistakes: check every sentence before you publish.
      • The preview frame has sandbox="": no scripts, and an origin of its own, so it cannot read this page or your key. Before the model's HTML reaches it, this page removes every script, event handler, meta http-equiv, base, frame and javascript: link, and every reference that is not a file in your folder; the frame then carries its own content security policy (default-src 'none'), on top of this page's.
      • Models offered: Codestral by default. mistral-vibe-cli-with-tools is in Mistral's model list, where it is named as an alias of Mistral Medium; it accepted a chat completion with tools in our test through Mistral's API on 21 November 2026. No Devstral model was in Mistral's model list when we read it on 21 November 2026, so none is offered. Press "Ask Mistral which models this key can use" to see the models your key has.
      • Prices for the cost estimate: Codestral 0.3 and 0.9 US dollars per million tokens, input then output, from its model card, as read on 21 November 2026; the Ministral and Small prices as on the team page. No price is shown for a model whose card we have not read. The EU endpoint is 1.1 times list price. Our estimate is not Mistral's bill.
      • The streamed chat and the tool loop are ported from PrompTugal News's chat-core.js (Apache-2.0), into /browser/ask/chat-core.js, shared with Ask this site.
      • This page talks to two places only: this site (to load its own files and the recorded run) and the Mistral endpoint you choose, with your key, when you press Run or ask for the model list. Its content security policy enforces that.
