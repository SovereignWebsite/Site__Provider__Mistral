Workflows on Mistral: the poster studio

A poster for your sovereign website

Write a brief. An art director on Mistral turns it into a commission: a headline, a tagline, a palette, and a brief for each of two makers. Then, at the same time, a painter asks Mistral's image tool for the picture, and a designer draws the whole poster in SVG. Both land on the wall side by side, each with the prompt and the model that made it.

Can Mistral make images from a browser? What we tested

Tested on 21 November 2026 between 02:56 and 03:12 UTC, from a script, with the Mistral key this site is built with, sending the same requests a browser sends:

  • Mistral's documented route did not work for that key. The image tool's page shows an agent created with tools: [{"type": "image_generation"}] (image generation, as read on 21 November 2026). POST /v1/agents answered 403: "Creating agents is not available for this organization. Use Managed Agents instead." Your organisation may differ.
  • The same tool works without an agent. POST /v1/conversations with model: "mistral-medium-latest", the tool in tools, and store: false answered 200 with an image. Its usage said "connectors": {"image_generation": 1}.
  • It works from a browser. api.mistral.ai answered the browser's preflight for /v1/conversations and the answer itself with Access-Control-Allow-Origin: *.
  • The picture is not on Mistral's own address. The answer gives a signed link on mistralaiblackforestprod.blob.core.windows.net, Microsoft Azure storage, which expired one hour after it was made. That host sends no CORS header, so a page can show the picture but not read it: this page shows it as an image from that host, and allows that one host in its security policy. The recorded run's picture is a copy kept on this site.
  • Which model paints is not stated. The image tool's page, as read on 21 November 2026, does not name the model or say what the picture may be used for. Mistral's Additional Product Terms (effective 25 September 2026, as read on 21 November 2026) have sections on "Third-Party Connectors" and "Third-Party Technologies", which "do not constitute Mistral AI Products"; they do not say whether the image tool is one. Read them, and ask Mistral, before you print a poster for money.
  • No price is published for it. Neither Mistral's pricing page nor the API pricing page lists a price for the image tool, as read on 21 November 2026. Our cost meter counts tokens only, and says "+ the image".
  • Not tested: the EU endpoint, api.eu.mistral.ai, for images.

What we found

One recorded run, 21 November 2026 at 03:12 UTC, art director and SVG designer on mistral-small-2603, painter on mistral-medium-latest with the image tool. The brief is for an imaginary bakery, not a real business.

  • Three calls in 13.0 s. The token cost was under a tenth of a US cent at list price; the image's price is not published.
  • The art director kept to the brief's rules: a three-word headline, a nine-word tagline, five colours, and an image prompt that asks for no words.
  • The painter's model rewrote the prompt slightly before it called the tool; the page shows both.
  • The picture has no text in it, as asked; the page sets the headline and tagline in its own type. The SVG designer drew the words itself, and put its loaf off to the right, on top of the tagline: a model drawing blind. The sanitiser kept its 16 elements and dropped nothing.

    What happens to a key from a QR code

    Opened as a link: the browser never sends the part after "#" to any server, and this page removes it from the address bar and this tab's history the moment it loads. Your camera app or browser may still keep the link in its own history, so treat that link like the key itself, and revoke the key in your Mistral console after the event. As a picture: decoded with your browser's own QR reader or, where it has none, jsQR, a copy kept on this site. Either way the page asks you first whether to use it, because anyone can send a link with their own key in it; then the key goes into the key box above, held in this tab's memory only, and is never shown.

    Where your key goes

    It goes in the Authorization header, and only when you press a button that sends something to Mistral. It is never stored, never shown, never sent to this site, and gone when you close or reload the tab. Use a key with a spending limit.

    On Mistral's free plan, what you send through the API may be used to train Mistral's models unless you switch that off in your Mistral admin panel (how to opt out, as read on 21 November 2026).

    How it works

    • The workflow is poster.js, run unchanged by the recorder and by this page; the drawing is flow.js, after the SGit-AI Web Summit stand's views by Angelo Leggio and the Galaxy by Silvio Switha's dashboard agent.
    • The picture is accepted only as an https link on the one host above, or as a file id fetched from Mistral's files endpoint with your key.
    • The SVG is model output, so it is never put into the page as markup. svgsafe.js rebuilds it from an allow-list of shapes, gradients, filters and text, drops scripts, links, images, styles and any url() that points outside the drawing, and the result is shown as an image from a blob: address, where a browser runs no script and loads nothing.
