PrompTugal on Mistral: bulletin

The day's bulletin, written by Mistral, checked in code

The day's facts for Portugal are picked in code from PrompTugal's public data: IPMA's weather warnings, sea and fire risk, and the cyber security lists of CISA and ENISA. A Mistral model writes a short bulletin from those facts only, in European Portuguese. Then code checks every number, hour and date against the facts, and that every place it must name is named. Mistral translates it into English and French with a glossary, checked the same way, and Voxtral reads it aloud and transcribes it back.

What this page reads, and from where

Five files from data.promptugal.news, read by your browser with a plain GET (no key, no cookies), only when you press "Read the data" in step 3. The content security policy of this page allows no other data host.

  • https://data.promptugal.news/api/v1/ipma-warnings/latest.json: IPMA's weather warnings.
  • https://data.promptugal.news/api/v1/ipma-sea/latest.json: IPMA's sea forecast, by coast.
  • https://data.promptugal.news/api/v1/ipma-fire-risk/latest.json: IPMA's fire risk, by municipality.
  • https://data.promptugal.news/api/v1/cisa-kev/latest.json: CISA's known exploited vulnerabilities.
  • https://data.promptugal.news/api/v1/euvd/latest.json: ENISA's EU Vulnerability Database, the last 24 hours.

PrompTugal collects these by code, twice a day for IPMA's sources, and each file says when it was read (data.promptugal.news, as read on 21 November 2026). IPMA's data may be used without a profit-making purpose only; this demonstration is not commercial. Not a warning service: follow IPMA and the civil protection authority, ANEPC.

What happens to a key from a QR code

Opened as a link: the browser never sends the part after "#" to any server, and this page removes it from the address bar and this tab's history the moment it loads. Your camera app or browser may still keep the link in its own history, so treat that link like the key itself, and revoke the key in your Mistral console after the event. As a picture: decoded with your browser's own QR reader or, where it has none, jsQR, a copy kept on this site. Either way the page asks you first whether to use it, because anyone can send a link with their own key in it; then the key goes into the key box above, held in this tab's memory only, and is never shown.

Where your key goes

It goes in the Authorization header, and only when you press a button that sends something to Mistral. It is never stored, never shown, never sent to this site or to PrompTugal, and gone when you close or reload the tab. Use a key with a spending limit.

On Mistral's free plan, what you send through the API may be used to train Mistral's models unless you switch that off in your Mistral admin panel (how to opt out, as read on 21 November 2026).

What we found in the recorded run

One run, 21 November 2026 at 02:02 UTC, mistral-small-2603 on api.mistral.ai, bulletin for Saturday 21 November, on PrompTugal data read at 18:04 to 18:15 UTC on 20 November. n = 1: an example, not a benchmark. An earlier test run the same night, without audio, gave the same checks.

  • All 15 figures in the Portuguese bulletin are in the facts; all 15 must-name items are named (Vanderbilt University as "Vanderbilt"); the weekday is right. Both translations keep all 15 figure values, every name and every glossary term.
  • What the checks did not catch: "com valores entre 1,7 m e 2,6 m nestas zonas" for Figueira da Foz and Lisboa. Lisboa's waves are 1,7 to 2,6 m, but Figueira da Foz's are 1,3 to 2,6 m. Each figure is true; the sentence stretches one coast's range over two. A figure check cannot see that: a person reading the facts can.
  • The round trip: 155 of the 161 words came back from Voxtral's transcription. Not heard as written: "PrompTugal" (heard as "Prom Portugal"), "m" (for metres), "CISA" and "BerriAI". Every figure was heard back with the same value. Whether the voice sounds European Portuguese is for a listener to judge: Mistral lists no Portuguese preset voice.
  • In a test run, the English translation came back wrapped in the <untrusted-data> markers we put around the Portuguese. The page now removes such markers in code and says when it did.

How it works, and what it does not claim

  • The facts are picked in code, with no model: bulletin-facts.js. A warning counts for the day if its window touches the day. The model gets only that JSON, inside <untrusted-data> markers, at temperature 0.
  • The figure check is figcheck.js: each number, hour and date in the text must appear in the facts. It cannot see a number written as a word ("oito"), or a true figure put in the wrong place. The must-name check catches an area, coast or vendor left out.
  • The weekday is computed in code from the date and compared with the one the text names.
  • The key box, the call function and "what this call sends, and to whom" are kit.js, shared with the other browser demos on this site, unchanged.
  • This page talks to three places only: this site, data.promptugal.news (without your key) and the Mistral endpoint you choose (with your key, when you press a button that says so). Its content security policy enforces that. Audio plays from memory in this tab (a blob address), nothing else.
  • The bulletin, the translations and the transcript are model output. Being checked in code does not make them right: read the facts.
