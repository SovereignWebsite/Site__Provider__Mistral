PrompTugal on Mistral: today

What should I know today?

Say where you are today, in London or in Portugal, and what you are doing. A Mistral agent decides which of PrompTugal's feeds to read, reads them through tools that run in your browser, and answers in a few lines, each with its source and when it was read. Every step is drawn as it happens: you, Mistral, the tools in this page, and the feeds.

What this page reads, and from where

When the model asks for a tool, your browser reads PrompTugal's public files itself, with a plain GET: no key, no cookies, no question text. Only from data.promptugal.news: the catalogue (/api/v1/index.json), a place's "now" file (/api/v1/by-place/now/<place>.json, for a place in that catalogue only) and a source's latest file (/api/v1/<source>/latest.json, for a source in that catalogue only); and from promptugal.news, its search index and the text of a page in it. The content security policy of this page allows no other data host. See all the feeds.

Each value keeps its source's licence; IPMA's data may be used without a profit-making purpose only, and this demonstration is not commercial. Not a warning service: follow IPMA and ANEPC in Portugal, the Environment Agency and the Met Office in England.

1. Replay a recorded run (no key needed)

Two questions we asked through Mistral's API on 21 November 2026, one in English and one in Portuguese, saved as a file on this site with every step. Replaying sends nothing anywhere.

2. Your Mistral key

Your key as a QR code

If you were given your key as a QR code: open its link on this device (the key comes after "#" in the link, and this page takes it from there), or paste or drop a picture of the QR code below. The picture is read here, in this tab, and sent nowhere.

Paste a picture of the QR code here (Ctrl+V, or Cmd+V on a Mac), or drop it here

What happens to a key from a QR code

Opened as a link: the browser never sends the part after "#" to any server, and this page removes it from the address bar and this tab's history the moment it loads. Your camera app or browser may still keep the link in its own history, so treat that link like the key itself. As a picture: decoded with your browser's own QR reader or, where it has none, jsQR, a copy kept on this site. Either way the key goes into the key box above, held in this tab's memory only, and is never shown.

What we found in the recorded run

One run of two questions, 21 November 2026, mistral-small-2603 on api.mistral.ai at temperature 0, on PrompTugal data read at 18:04 to 18:16 UTC on 20 November. n = 1 per question: examples, not a benchmark.

  • London and Lisbon: the agent read the two place files and no more, and named Lisbon's yellow rain warning (12:00 to 18:00) first, as the prompt asks. Every figure in the answer is in the data, but one is rounded: London's maximum is "9 °C"; the data says 9.4. The figure check counts "9" as found because a 9 appears elsewhere in the data.
  • Faro, asked in Portuguese: the answer came in English, against the prompt. And "Sea temperature up to 19.4 °C today" is the figure for 20 November in the file, not for the 21st.
  • So three faults that code checks of figures cannot see: a rounded number, the wrong day, the wrong language. The flow and the steps show exactly what was read, so a person can check.

How it works

  • Five read-only tools, in pt-tools.js: read_place (one place's "now" file), list_sources, read_source, search_news and read_news. The model never gives an address: it names a place or a source from PrompTugal's catalogue, and the address is built in code.
  • The prompt is today.js: start with the places named, at most five tool calls, at most five lines, a warning always a line, each line with its source and read time.
  • The loop and the key panel are chat-core.js and panel.js, unchanged. Every tool result goes back to the model inside <untrusted-data> markers. A link in an answer is clickable only if a tool returned that exact address, on PrompTugal's, IPMA's, the UK government's, Open-Meteo's or the vulnerability databases' hosts.
  • This page talks to four places only: this site, the Mistral endpoint you choose (with your key, when you press Ask), data.promptugal.news and promptugal.news (without your key). Its content security policy enforces that.
