Evals: the same work, on different Mistral models

Every number on this page is computed here, in your browser, from the signed run files: only runs whose signatures verify are counted. A check is code, not a model: is the JSON valid, is the quoted sentence really on the page, are the numbers in the note the measured ones, is the translation in the right language.

Nothing has been agreed with Mistral AI.

How to read this

  • First try: the share of steps whose first call passed every check. In the end: the share that passed within the packet's three tries (each retry is told which checks failed).
  • Some checks are rough heuristics: looks_pt and looks_fr count common short words, so a short or name-heavy translation can fail them while being right. The model output is on the replay page, so you can judge it.
  • Few runs, small samples: this is a demonstration of the method, not a benchmark. Each count links to the replay of the runs behind it.
  • Cost is computed from the usage tokens Mistral returned and Mistral's published prices (docs.mistral.ai/inference/pricing, as read on 20 November 2026).
