2. Your Mistral key

Held in this tab's memory only: never stored, never sent anywhere but the Mistral endpoint you choose below (POST /v1/chat/completions). Close the tab and it is gone. Calls are billed to your Mistral account at Mistral's prices; each packet carries a budget and the engine stops calling when the run reaches it. Make a key with a low spending limit for demos like this one. If your browser offers to save this key as a password, choose Never.
