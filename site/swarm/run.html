Run the swarm yourself, on your own Mistral key

The same signed packets, run by the same engine, in this tab. Your key stays in this tab's memory and goes only to api.mistral.ai. In step-by-step mode you see each request before it leaves, and you send it.

Nothing has been agreed with Mistral AI.

1. Choose a packet

2. Your Mistral key

Held in this tab's memory only: never stored, never sent anywhere but the Mistral endpoint you choose below (POST /v1/chat/completions). Close the tab and it is gone. Calls are billed to your Mistral account at Mistral's prices; each packet carries a budget and the engine stops calling when the run reaches it. Make a key with a low spending limit for demos like this one. If your browser offers to save this key as a password, choose Never.

Key: none.

Which Mistral endpoint

Before you use a key on Mistral's free mode: Mistral says free-mode API data may be used for training unless you switch it off (how to opt out); API inputs and outputs are kept for abuse monitoring, and zero data retention is available on request on paid plans only (Mistral's help page).
