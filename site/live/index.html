Agents at work

The agents that built this site, which of them are running now, and when each one fired. A fire is a commit: every commit names the agent that made it, and a commit that names another agent is drawn as a flow between them. Drag the timeline to watch the night unfold, from 22:51 UTC on 20 November to now.

    How this page knows

    • The roster is a file on this site, /data/agents/roster.json, kept by the conductor. It lists every agent with its kind, job, section and state, and names only: no session links or ids.
    • The fires are the commits on the dev branch, read by your browser from GitHub's public API when the page opens and when you press Refresh, and kept in memory only. Each commit's Agent: line names the agent that made it. GitHub allows 60 such requests an hour for each address without a login; when it says no, or cannot be reached, the page shows a snapshot of the commits saved on this site, and says when it was taken.
    • Active or retired comes from the team's public list of agent keys in the Factory repository, read for names and status only.
    • Nothing else. No cookies, no storage, no tracking. Nothing about you is sent anywhere, except that GitHub sees your browser's requests for the commits and the key list, as it sees any visit. Commit messages are shown as plain text.

    The drawing

    The idea is Gravity, from the SGit-AI Web Summit stand: a core, centres of gravity around it, the nodes that belong to each centre, and the flows between them, where a commit that names another agent counts as a message. Gravity is Apache-2.0, so it could be copied here. We drew our own version in SVG instead, for three reasons: version 0.1.0 loads three.js and two fonts from other sites at run time, it styles itself with inline styles that this page's security policy refuses, and it needs WebGL. This drawing is plain SVG made by one small script on this site, needs no WebGL, and its data has Gravity's own shape (core, centres, nodes, flows, feed), so the library could draw it later.

    With reduced motion set on your device, the drawing stays still at the current time and the replay is off; the timeline still moves when you drag it.
