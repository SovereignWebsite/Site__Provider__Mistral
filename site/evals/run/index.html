Run the evals in your browser

The same suites and the same code that made the published results, running in this tab. Your browser calls the provider you choose directly; this site has no server and never sees your key or your results.

1. Provider and key

No key set.

The key is kept in this tab's memory only and is gone when you close or reload the tab. It is never stored, and it is sent only to the provider you chose, never to this site. A key with a low spending limit is a good idea. If your browser offers to save this key as a password, choose Never.

Before you send anything: on Mistral's free mode, API data may be used for training unless you switch that off in your Mistral admin settings (Privacy), and Mistral keeps API inputs and outputs for 30 days for abuse monitoring. The suites here hold only made-up test data. The EU endpoint processes requests inside the EU and is priced above the global one; the global endpoint makes no promise about where inference runs. Source: Mistral, regional inference, as read on 20 November 2026 by the team's research agent.

For Ollama, start it so that it accepts calls from this page, for example OLLAMA_ORIGINS=https://mistral.provider.sovereignweb.site ollama serve, and pull a model with tool support. Only localhost and 127.0.0.1 on port 11434 are allowed by this page's security policy. Your browser may ask before letting a public page reach a local address.
