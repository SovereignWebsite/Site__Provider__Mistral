Use this site with AI

This site is written for people and for AI agents. Point your agent at llms.txt and tell it who you are; it will find the right instructions. Any model will do, Mistral’s included: that is the point of the site.

If you are visiting

Paste this into any assistant that can read web pages:

Read https://mistral.provider.sovereignweb.site/llms.txt and follow the instructions for a visitor.
Then answer my questions about Mistral, a European brain for a sovereign website, with a link for each point,
and say plainly when the site does not say something.

If you own this site

Give your agent write access to the repository (see Start here), then tell it:

Read https://mistral.provider.sovereignweb.site/llms.txt and follow the instructions for the owner.
I want to change: [describe the change].

For agents

  • llms.txt: what this site is and what to do, by who you act for.
  • Sources: every fact with its source and the date it was read.
  • data/agents.json: the agents that work on this site.
  • The repository: every file and every change.
