# Five designs for mistral.provider.sovereignweb.site

Concepts first, before building (design.b, 20 November 2026). Each design rebuilds the page from the same facts; none is a reskin. Every design carries, near the top: "An independent Sovereign Website demonstration. Not affiliated with or endorsed by Mistral AI." Every fact links its source and the date it was read.

## 1. The European brain (newsroom feature)
- Idea: Dinis Cruz's article, "A European brain for a sovereign website" (20 November 2026), told as an editorial long read.
- Centre: the claim "the model is a choice the owner makes, like the host".
- Focus: the three levels (on the device, in the EU, any provider), pull quotes from the article, the licence to watch, what was already run, the partnership as a proposal (nothing agreed with Mistral).
- Main action: "Try it yourself" into the demos.

## 2. The map
- Idea: where the data goes. An SVG drawing of the path from the visitor's browser to each choice: their own device, Mistral's EU endpoint, another provider through their own key.
- Centre: the diagram, drawn only from published regions and terms.
- Focus: what is sent, to whom, what is kept and for how long, per path.
- Main action: pick a path and open the matching demo.

## 3. The console
- Idea: the playground first. Provider and model picker, a brief, the answer, tokens and time per call.
- Centre: the live call with the "What this call sends, and to whom" panel beside it.
- Focus: the same OpenAI-style code for every provider; the visitor's own key, kept in the tab.
- Main action: run the same brief on Mistral beside another model.

## 4. The ledger
- Idea: the sovereignty checklist as a table the visitor fills in for their own set-up: who holds the keys, where it runs, which licence, how long data is kept, can you leave.
- Centre: the table, with Mistral's three levels filled in from cited facts as the worked example.
- Focus: the visitor's own answers, computed in the page and never sent anywhere.
- Main action: fill in your own row.

## 5. The hackathon
- Idea: the briefing for participants on Saturday 21 November 2026, as an event poster with the date as the hero.
- Centre: start here, the three demos, what to build, how to share it.
- Focus: get someone from zero to a first call in five minutes with their own key or a local model.
- Main action: open the first demo.

Ship order (deadline Saturday): 1 and 5 first, then 3, 2, 4.
